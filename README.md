# GitHub-Actions-Automated-Docker-Deployment-on-AWS

AWS DevOps project demonstrating automated Docker deployment using GitHub Actions, AWS services, and CI/CD pipeline.

## Architecture
- CI/CD: GitHub Actions -> ECR -> ECS (Fargate)
- App: Containerized Employee Information Web Application using Docker
- Auth: GitHub OIDC -> AWS IAM Role (Temporary Credentials)
- Monitoring: Amazon CloudWatch Logs

## Tools Used
- AWS: ECS, ECR, Fargate, IAM, CloudWatch
- Docker, GitHub Actions, Git, Linux
